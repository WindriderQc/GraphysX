# CubXActor lineage inspection layer

This layer displays the recovered `Media/CubXActor` family without merging it into CubZ. The archive evidence does not provide a stable semantic click-index-to-`BoxNN` mapping: the click meshes, Get filenames, full-open panel name, solo-open panel name, and broken eighth host slot contradict one another. This is therefore an inspection environment, not a replacement CubZ menu implementation.

## What is exact

- Indexed positions, normals, UVs and triangle indices decoded from the 16 byte-distinct TVA files.
- Closed `CubXMesh.tvm` and all eight `CubXBtnN.tvm` companion meshes.
- MHI2 hierarchy and initial local matrices.
- MANS ranges at 30 fps, substantive MANI keys, and archived Get/Open terminal holds.
- Host click flow: clicks 1..7 call actor slots 0..6 loaded from `CubXGet2..8`; click 8 reaches uninitialized slot 7 and is not covered by the 0..6 render loop.

`src/legacy/cubx-actor-inspection-geometry.json` is generated by `tools/convert-cubx-actor-lineage.mjs`. Its actor data is deduplicated into eight exact geometry payloads while each audit asset retains its source hash and payload references.

## Inspection-only adapters

- Raw TV3D matrices and quaternion component order are applied directly to Three.js. A handedness conversion is not claimed.
- Between stored keys, vectors use linear interpolation and rotations use normalized shortest-arc SLERP. The original TV3D interpolation routine has not been recovered.
- Diagnostic materials, wireframe click proxies, lighting, grid and camera are modern inspection aids.
- Reverse playback is available for study, but the recovered host contains no literal Rot calls and its close/deselect state bodies are empty.

## Preview

Open `/cubx-actor-lineage-preview.html` through Vite. The preview exposes Closed, Get, Rot, Open and Solo families; pairs/clicks 1..8; play/pause, single-frame steps and direction; click proxies and diagnostic colors; pointer orbit/zoom; and structured evidence in `render_game_to_text()`.

Click 8 remains selectable as a red defect record. It never swaps in an invented actor.

## Minimal integration API

`CubxActorLineageEnvironment` in `src/cubx-actor-lineage-environment.ts` owns a mountable Three.js `group` and these operations:

```ts
const actor = new CubxActorLineageEnvironment();
scene.add(actor.group);

actor.setClip("closed");
actor.setClip("get", 1);       // pair 1 -> CubXGet2.tva
actor.setClip("rot", 1);       // exact asset, host use not claimed
actor.setClip("open-full");
actor.setClip("open-solo");
actor.selectClick(8);          // defect inspection; no invented slot
actor.setSourceFrame(30);
actor.stepFrames(1);
actor.setDirection(-1);
actor.setPlaying(true);
actor.advance(deltaSeconds);
actor.setButtonsVisible(true);
actor.setDiagnosticColors(true);

const state = actor.getState();
actor.dispose();
```

The safest product integration is a separate Archive Lab/CubXActor lineage destination. Do not bind this API to CubZ cube identities unless additional source evidence resolves the contradictory `BoxNN` lineage.

## Verification

```powershell
node tools/convert-cubx-actor-lineage.mjs
node tools/verify-cubx-actor-lineage.mjs
node scripts/qa-cubx-actor-lineage.mjs http://127.0.0.1:4191
```

The browser QA covers all 16 actors, exact geometry totals/ranges, terminal holds, deterministic time, all seven valid host flows, broken click 8, diagnostic toggles, invalid-input rejection, and console/page errors. Captures and a JSON assertion report are written to `output/playwright/cubx-actor-lineage/`.
